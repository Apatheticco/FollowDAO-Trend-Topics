# LESSONS — create-trending-topic 实战教训档案

> 本文件是 SKILL.md 的姊妹档案：SKILL.md 只留**规则结论**（每轮扫描全量进 context），完整的事故经过、实测数据、版本演进归档在这里，**按需查阅、不随每轮加载**。规则有疑义时回这里看"为什么"。

## 时间与会话状态

### bash date 冻结（v2.5.4，2026-06-08）
会话 compact 续接后，沙箱时钟冻结在快照时刻：`date` 说 06-06 14:28，真实已是 06-08 09:26，**差 2 天**。靠三角校验（currentDate + live twitter 时间戳 + 价格跳变幅度）发现。后果模式：拿 N 天前的去重池当当下、窗口全错。

### 会话记忆失真（v2.6.0，2026-06-12）
开跑时凭印象认为"5 分钟前刚跑完刷新"，实际上轮是**昨天**（间隔 4.8h+跨天），差点复用过期价格快照和 B0。与 date 冻结不同——这次 date 是准的，错的是**对上轮时间的会话记忆**。修复：间隔一律由时间戳文件计算。

### 时间戳文件按天命名自陷阱（v2.6.5，2026-06-20）
一个会话内连续 3 次跨天（06-18→19→20），每次时间戳 helper 都失灵。根因：文件按天命名 `-YYYYMMDD.txt` + 开跑只读当天文件——而当天那个文件年初还不存在，`tail` 拿空值，算出 `间隔 29698777 min` 乱码。且命名格式三处不一致（执行卡 glob `*`、增量铁律 `-YYYY-MM-DD` 带横杠、实跑 `-YYYYMMDD` 无横杠，混排时 `-`(0x2d)<`0`(0x30) 还会乱序）。v2.6.0 的规则没错（≤30min 复用/跨天作废），靠三角校验每次都救回来了，但载体有坑。修复：collapse 成单一 append-only `/tmp/trend-scout-last-refresh.txt`（不带日期），永远 `tail -1`，跨天天然连续。

### "看看 X"被当"建 X"（v2.6.5，2026-06-20）
用户「看看 SK 海力士的话题」是让我调研有没有/值不值得，我直接 create 了 → "你创建了个啥"。同一会话存储板块那次学乖了先 present。根因：入口只分 (B)素材/(C)标的，没区分**调研型问法 vs 建题型指令**。修复：加意图闸——"看看/有没有/查一下 X"=先 present+评分+去重、问一句再建；"建/补/拆/上线 X"=才走建题。

## 数据源 quirks 完整实测记录

### quirk⑨ 大宗裸 keyword（2026-06-03）
`metrics(keywords=["gold"])`→Barrick Gold 金矿股 $39、`["oil"]`→油股、`["CL"]`→Colgate 牙膏、`["BZ"]`→看准网中概。`query="price now"` 不能修（数值照错、体积照炸 66K）。实测正解值：XAUT $4,416/oz、CLUSD WTI $94.95、DXY 返 DXUSD 99.4。

### quirk⑩ categories=["market"]（2026-06-05）
不传时 metrics 扇出 macro+fundamentals：tradfi 2 股溢出 130K token、12 股 700K；crypto 混入 ~10 行 macro 噪音（kw_not_canonical + EIA 汽油）。加 market 后 tradfi 直接带 change/dayHigh/marketCap/yearHigh，旧"存盘提取"流程全废弃。

### quirk⑪ keywords 10 上限（2026-06-06）
28 keywords 被静默截断到 10，仅返回 warning `keyword_count_over_max: keywords truncated: 28 → 10`，不报错不补返回——漏了 18 只股的数据而不自知。涨榜 `biggest gainers` 配 `min_market_cap=1e9` 返回 `source_dead:min_market_cap_excluded_all`（gainers 端点 marketCap 字段为 null）。

### quirk⑫ econ 日历（2026-06-10）
默认 lookback_days=7 只向后看，永远捞不到未来 CPI/PPI。我在 review 中曾**错误断言**"结构性只能向后看、建议删除该调用"——用户问"经济日历现在能正常获取吗"，实测传 date_from/date_to 即返前瞻。教训：**先实测再下结论，review 也不例外**。传 keywords（US/nfp/PAYEMS）会每个各回 10 条相同的 JP/KR 噪音 = 60-90 行垃圾。

### quirk⑬ MCP 重连数组 bug（2026-06-10）
followin 断线重连后 `["BTC"] has type "string", want array`。三组对照实验定位：纯 query 正常、显式数组全挂、twitter(字符串参数) 正常 → harness 在 ToolSearch 回拉 schema 时丢失 `"type":"array"` 标注，序列化成 JSON 字符串。非服务端宕机、非 skill 错。用户重启 server 后即愈。

## 扫描完整性

### 5/19 漏 list + TG：缺 5+ 强候选
跑首扫漏掉 Twitter list 和 TG 频道 → 直接缺 Google×Blackstone / 马斯克 OpenAI 败诉 / 黄仁勋 Computex / 韩国零售融资 / Pumpfun 抛售 5 个 megaevent。这些只在 Twitter list + TG bot 出现，新闻通道捞不到。由此把三栈 list + TG 设为必跑批次。

### 5/14 漏 H200 出口许可（v2.1.7）
刷新只跑 `asset_type="tradfi"` 通道，漏掉路透社独家 + 中文媒体爆点。FMP 通道偏 WSJ/Bloomberg/Barron's 严肃财媒。由此 query 兜底（不传 asset_type）设为必跑。

### 6/8 合并波丢批
Wave 合并提速时把 TG 批和 XAUT 金价整批丢掉，用户问"检查一下跑完整了吗？"才补。教训：**合并≠丢批**，合并后逐项对照执行卡打勾。

### 6/8 抢报"干轮"
增量明明有 N1/N2 真候选，被我当"色彩"埋进正文就报了干轮，用户反问"这一轮没有新增的吗"。教训：先全列候选再下干轮结论。

### 6/18 SK 海力士被埋成印证脚注（v2.6.4）
首扫抓到了 SK 海力士 12 层 HBM4E 样品 + 美光弃 NOR，但我把它当成"苹果因成本涨价(N1)"那条线的**背景印证**写进正文，没独立立项。实际重要性倒挂：SK 海力士才是这条线最直接的主角（HBM4E 样品首发=技术里程碑 + 韩股创历史新高 + ADR/$664 亿回报 + EWY 年内 +112%），是独立 P0；苹果涨价反而是下游色彩。要不是用户点名"看看 SK 海力士"，这条 P0 就漏发了。同类病=6/8 抢报干轮（真候选当色彩埋正文）。修复立"印证型候选回查铁律"：被当印证的料回头单独打分，≥P1 就独立立项。
附带教训：建题时还误用了新闻里 06-17 的 +5.46%（隔日盘中数）进标题，直到用户让查才 WebSearch 出当日 +4.44%（₩2,633,000）。followin 对韩股无覆盖（实测 000660.KS/HXSCL/HYNIX/SKHYNIX 全空），这类非美个股**必须当场 WebSearch 取当日价**，不能将就新闻里的隔日数。立"非美个股价格盲区→WebSearch 兜底"铁律。

## 事实与措辞红线

### KOSPI"熔断"失实（v2.5.3，2026-06-08）
9634 把 KOSPI −6.4% 写成"触发熔断"（韩股一级熔断 = 跌 8% 持续 1min，−6.4% 不构成）；9698 又脑补了"二次"。用户问"核实一下，真的是二次熔断吗"。两条分别撤回/改标题。由此立硬定义词红线：触发熔断/创新高/首次/史上最大等必须对源核实定义是否满足，缺证据降级措辞。

### 黄金标题归因（2026-06-10）
9759 初版写"停火浇灭避险买盘"——黄金是多因子标的（美元/实际利率/央行购金，当时中国还在增持），单一归因是猜测。用户："这个归因感觉不太好，可以主要从价格走势上去写"。由此立多驱动标的标题只写走势规则。

### 时效违规判例（v2.2.8，5/26）
「Saylor 本周买债券非 BTC」published 5/24、「中本聪 OG 抛 2650 BTC」published 5/25，5/26 首扫均超 24h 仍进了表，被用户标时效问题。"事件还在演进"不是豁免理由。

## status 与发布机制

### v2.5.2→v2.5.6 status 反转（2026-06-10）
v2.5.2 曾断言"create 返回 status=2 = 停在审核"。用户发现话题直接上线："你是不是搞错状态了"。实测：create 返回 2，但系统后台几分钟内自动推到 0。v2.5.2 全面收回。报告 status 一律 list 实查；要留审核必须主动 update 按住。

### 盘后数据脱锚（v2.6.0，2026-06-11）
9784 用"盘后跌 7%"建题，收盘实际 −12%，脱锚挂了一整天，且系统自动批 10000001922 后发了更准版（−12%）造成双份并存。由此立盘后数据收盘复核 + 撞车处置两条规则。

## 非美个股取价降级梯（v2.6.7，2026-06-22）

用户"出一下韩股 SK 海力士话题"，我第一轮只跑 WebSearch（韩媒只回 forecast ₩2,960,213、英文回 06-18 旧值），就下结论"今日实际价取不到"——被用户"不能检索到当前实时价格吗"顶回。按"先实测"把降级梯走到底：`tradingview yahoo_price` SSL EOF 挂、`stockanalysis` 403、Naver 被封，但 **`WebFetch google.com/finance/quote/000660:KRX` 通了**，回 ₩2,943,000 / 前收 ₩2,764,000 / +6.48%（数学自洽、dated 实际成交非 forecast）。教训：`followin 无覆盖 ≠ 全网取不到`，一级失败不等于取不到，降级梯（WebSearch→tradingview→Google Finance WebFetch）必须走到底再认输；forecast 价一律弃用。已写入 SKILL v2.6.7。

## TG 频道降级实测（v2.6.6，2026-06-20）

用户问"TG 来源是不是价值很低"，按"先实测"抽了工作日+周末两批共 ~36 条复核：
- **裸 feed（空 query / category browse）= 纯 bot 噪音**：爆仓 bot（微额 $50K）、匿名巨鲸流水（Unknown Whale↔Aave，撞链上红线）、喊单/meme shill bot（FalkorDB x8 call、$BULL/$TOESCOIN/$JOBBY）。两批 topic-worthy≈0，工作日非周末假象。
- **query 模式略好但 ~70% 仍噪音/重复**：捞到 FOMC 加息、STRC 跌破面值、Illinois 加密税、India ED 突袭、CZ 谈代币化——但全被 media/三栈 list 覆盖。
- **TG 唯一残余独有价值 = 安全/exploit 早警**（Axelar $4.7M 桥被盗、Aztec $2M），偶尔比 media 快几分钟；连这个常规 news 的 `hack exploit` query 也部分覆盖。
- **真叙事价值在三栈 list 不在 TG**：本会话出真候选（SK 海力士换帅、半导体、MS ETF）全来自 list；5/19 "list+TG 缺 megaevent" 的功劳大概率主要是 list，TG 搭便车被记成必跑。
- 处置：5-cat browse 全删，只留 1 条 exploit 探针（`query="hack exploit drained bridge vulnerability"`）；强制铁律改为"三栈 list 不可跳过、TG 已降级"；ETF netflow 从 TG bot 改走 media query。
