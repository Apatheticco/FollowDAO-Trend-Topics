description: >
  从原始素材或主动扫描热点，自动提取结构化字段，创建 Followin 热点风向标（TrendingTopic），并支持发布。
  三种触发场景：
  (A) 用户让"扫一下热点 / 找几个话题 / 批量创建今日话题" → 调 Followin MCP（metrics/news/signal/twitter）主动扫描；
  (B) 用户给一段素材（新闻/推文/描述）让创建话题 → 直接进评分；
  (C) 用户给一个标的或一句话（"查一下 REPPO" / "Aave 现在情况"）→ 多源补全资料再评分。
  ⚠️ 调研型 vs 建题型意图闸（v2.6.5）："看看/有没有 X 话题 / X 板块怎样 / 查一下 X"=**调研型→先 present 数据+评分+去重结论，问一句再建，禁止直接 create**；"建/补一个 X / 把 X 拆成 N 条 / 上线 X"=建题型→按 (B)/(C) 走。（LESSONS v2.6.5）
  全流程：采集 → 去重 → 评分 → 字段提取 + 标题优化 → 预览 → 创建 → tag 校验 → 数据核实 → 发布。

## ⚡ 执行卡（每轮照此跑，细节见 `references/` 详章——文末索引）

### 0. 开跑前（铁律）
```bash
date '+%Y-%m-%d %H:%M:%S %Z (UTC%:z) | Unix: %s'   # 必跑，算 cutoff_4h/24h
tail -1 $HOME/.trend-scout/last-refresh.txt 2>/dev/null   # 必跑，上轮真实时间戳
# 跑完一轮在结尾追加：  echo "$(date +%s)000" >> $HOME/.trend-scout/last-refresh.txt
```
> - 🗂️ **时间戳 = 单一 append-only 文件**（v2.6.5/v2.8.1）：文件名不带日期、`tail -1` 取末行；禁止按天分文件（跨天读空文件算出乱码间隔）。放 `$HOME/.trend-scout/`（`/tmp` 会被系统清，cron 致命），开跑 `mkdir -p ~/.trend-scout` 兜底。
> - **判模式**（v2.8.8）：`last-refresh.txt` 末行与当前 date **跨天 = 当天第一轮 → 🟢首扫(24h)；同日 → 🔵刷新(4h)**。判据客观化、禁止凭会话记忆；用户显式说"跑首扫/刷新"以用户为准；今日 status=0 发布 0 条 → 强制首扫兜底。~~旧钟点判据~~ 作废。
> - ⏱️ **跨轮间隔一律按文件时间戳算**（v2.6.0——compact/隔天续接后会话记忆必然失真）：**≤30min** 复用上轮价格快照/B0 只补增量；**>30min** 价格重拉；**跨天 → 价格 + B0 去重池全部作废重拉**（v2.5.4：旧池子当当下是最危险的错）。
> - 📸 **收尾双留档**（v2.8.3，效果评估地基，同为 append-only）：① **B0 快照** → `~/.trend-scout/snapshots.tsv` 逐条 `run_ts<TAB>id<TAB>domain<TAB>status<TAB>created_at`（API 无变迁历史，没快照算不出采纳/打回/误撤率）；② **写操作日志** → `~/.trend-scout/actions.tsv` 逐条 `run_ts<TAB>action(create/cull/merge-keep/merge-hide/update/publish/restore/rulefix/note)<TAB>id<TAB>备注`。周复盘吃这两份（`references/weekly-review.md`）。

### 1. 并行批次表（同一格 = 同一 turn 内并发；followin 单批 ≤5 防掉线）

> 🧱 **三条硬约束**（v2.9.4/v2.9.8）：① `metrics` 的 **keywords 每次硬上限 5 个**——超了**静默截断**到前 5（返 warning），10 币拆 2 批、板块矩阵每批 ≤5；② B0 `list_trending_topics` 的 **date_range 必须含今天**（跨天写 `昨天~今天`），否则漏当天新题、误报"8h 池为空"；③ B0 **`limit=100`（API max）+ 满额守卫**：`total == limit` 即视为可能截断，缩 date_range 或分 status 拆两次拉齐——截断都是"看不见的漏扫"。
>
> ⚠️ **数组参降级闸**（v2.9.13）：本表 `metrics` 默认数组参；会话注册表剥空报 `-32602` 时**整表改 query 形态**——`metrics(query="<实体空格串> price snapshot", asset_type=...)`，实体 ≤5/批照旧（代价：categories 锁不住、macro `kw_not_canonical` warning 属噪音）。判型见「🔧 通道故障分型速查表」。

### 2. 候选处置路由（status × create_at 年龄 → 走哪条规则）

> 🔁 **轮内执行序铁律**（v2.8.5）：每轮固定四步、顺序不可倒——**①扫热点**（§1 全跑）→ **②盘 8h 池**（B0 圈出 `≤8h` 全量，status 0/2 都要）→ **③处置存量**（改/合并/撤全做完：≤6h 上线题退场复查 v2.6.8、≤6h 审核题质量复审 v2.7.7、≤6h 重复合并 v2.7.3、时段闸内改价 v2.7.8——三项复查窗统一 6h；8h 只是素材 update 承接窗）→ **④最后才补新题**。**禁止先建后盘**：补题的去重基准=处置后的池子；能 update 承接的不新建。报告顺序仍 🆕补 最前，执行顺序补题最后。AUTO 同样适用。

> 🕗 **8h 管理视野闸**（v2.7.1）：扫描只管 `create_at ≤8h`；**>8h 一律不管**（不复查/不脱锚撤/不升温/不进决策/不提），当前催化由**新话题**承接。8h 是单一管理边界。（LESSONS v2.7.1）

| status | create_at 年龄 | 处置 |
|--------|------|------|
| **0 上线** | ≤8h | 数据偏差 ≥10%→升温 update；>25%→撤；>50% 反向→强撤（=退场复查）；**A≤1 灌水已上线也直接撤**（v2.9.2，见 A 闸统一节；例外：带明确未来日期的空投/上线预告可留）|
| **0 上线** | **>8h** | 🚫默认不管；当前行情→新建。**破闸例外全清单**（v2.9.8 集中）：① 事实错误（v2.9.4 硬数字/硬定义词失实，仅限客观可证）；② 盘中反转错向（v2.9.6，fact-check 必校方向）；③ 碎片/重复卫生（→去重统一树）；④ tag 卫生（v2.9.5 顺手 force-set）。8h 闸防"追新脱锚"，不豁免"错的东西挂在前台" |
| **2 审核** | ≤6h | v2.7.7 质量复审（每轮固定动作）+ 0a.5 预过滤 → ✅发 / 🟠改 / 🚨撤 / 🟡待核（表 3 必列）|
| **2 审核** | **>6h** | 🚫**一律忽略**（v2.9.18）：不复查、不跟进、不进报告、不催（2026-08-04 梳理统一旧 8h 口径为 6h，依用户 07-30「超过6小时就自己忽略」）|
| **3 hidden** | — | 不重建、不分析 |

> **🔁 近 6h 上线话题退场复查**（v2.6.8）：每轮从 B0 挑 `status=0 且 ≤6h` 逐条：① 脱锚/失实/过期→`status=3`；② 数据旧但成立→update；③ 仍准确→不动；④ A≤1 灌水上线不豁免直接撤（v2.9.2，meme 除外——见 A 闸统一节）。>8h 不进。系统批只扫明显错误，自建逐条过。（LESSONS v2.9.2）

> **🔎 近 6h 审核池质量复审（v2.7.7 + v2.9.20 每轮固定动作）**：与退场复查配对，每轮从 B0 挑 `status=2 且 ≤6h`（含系统批量建的）逐条审，不合格直接 `status=3`。**不合格四类（任一即撤）**：① **A≤1**（→下方统一节硬判据）；② **链上红线**（匿名对赌/机构例行托管流水）；③ **事实红线**（硬定义词失实/隔日数进标题）；④ **灌水噪音**（空投/上币类；~~小币 meme~~ 已废→A 闸统一节豁免）。合格=清晰标的+强催化。>6h 不进。

>    - **真不同切面 → 都留不合并**：标题主语=**不同实体/标的/因果层**（技术根因 vs 市场反应）**且**各自独立数据锚（不同源不同量纲）。反例：Wanchain `10730`(签名重放机理) vs `10745`(NIGHT 价格情绪)——我以"数字更硬"误合并，团队恢复。**"数字更硬"只说明质量高，不说明另一条是重复**（v2.9.15）。

### 3. 评分 → 三件套 → 建/核/发

- **⏳ 0b.0 时效双闸（v2.9.25 — 原只有①，②是 2026-08-04 用户「这种新闻你注意点时效，时效太差就去掉」补的真空白）**：两闸独立，**任一不过即砍，不进评分**。
  - **① 发布时效**：`published_ts` 超窗（首扫>24h / 刷新>4h）→ 砍。
  - **② 内容时效（新）**：**判「这条催化描述的动作发生在什么时候」，超出扫描窗即砍——不论 published_ts 多新**。触发词：**上周／上月／过去 N 天／累计／季度／13F** 等回溯性表述。典型=**机构例行披露**（8-K 周报、持仓更新、13F）、周度月度统计——这类 published_ts 永远是今天（必过①闸），但动作早被市场消化，今日不构成可交易催化。
  - **⚠️ 必须独立成闸、不能靠 A 闸兜**：这类**常常有标的**（MSTR/BMNR 股票、ETH），A≤1 拦不住。

## 🎯 管线与理念（v2.2，压缩版 v2.9.9）
