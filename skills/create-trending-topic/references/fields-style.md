# 字段与标题写法（参考件）

> **v3.7.15 精简**：建题流程（预览→`topic.py create`→下游回读→核实→上线）、标题长度/ticker 主语、数字口径、发布权一律以 gates.md 和脚本为准（`gate.sh 建题核实`／`标题样式`／`数字`／`发布三问`）。本文件只留 gates 没收的写法细则；与 gates 或 `lint.py`／`topic.py` 冲突时以后者为准。v2.x 原文（直调 `create_trending_topic`、25 字上限、问句尾许可、「询问用户后发布」、批量核实四步等已作废口径）在 git `0deeaa3` 版本。

## 标题

**样式（`topic.py` 预检跑 `lint.py`，FAIL 拦）**：

| # | 规则 | 正例 / 反例 |
|---|------|------------|
| 1 | **主体前置**：ticker／公司名／中文简称开头，不铺垫 | ✅ `Apple涨3.6%，…` ❌ `消息称Apple…` |
| 2 | **双分句**：`主体+涨跌动词+幅度，诱因/补充` | ✅ `Meta大涨7.9%，宣布出售过剩AI算力切入云业务` |
| 3 | **分隔只用逗号「，」，不用冒号**（冒号开头会被 lint 判成 KOL 观点题）；顿号只用于并列 | ❌ `Circle 暴跌 17.5% 创新低：140家…` |
| 4 | **数字与文字紧贴、无空格** | ✅ `大跌5.8%` ❌ `暴跌 17.5%` |
| 5 | **涨跌动词按幅度选**：涨(≲5%)→大涨/走高→暴涨/飙升(≳10%)；跌→大跌/走低→暴跌/重挫(≳8%) | `Corning暴涨16%` |
| 6 | **板块题**：`X板块整体走高(下跌)，A涨x%、B涨y%领涨(跌)`，≤2 个代表标的 | `半导体板块整体下跌，AMAT跌7.8%、MU跌6.9%领跌` |
| 7 | **长度 ≤30 字（目标 20–28），主语+动作+至多 2 个数字锚** | → `gate.sh 标题样式` |
| 8 | **幅度只由 `pct.py` 算**：\|x\|≥10 取整、<10 一位小数；大额用 亿/万亿 | → `gate.sh 数字` |
| 9 | **价格关口写「数字+货币单位」**：`跌破7万美元`、`站上4000美元` | ❌ `跌破$70000`——lint 认不出价格腿，报「双要素-缺价格」 |

- **补充分句必须带增量信息**（诱因/数据/日期/对手方），禁空泛尾巴：`引发市场关注`／`热度升温`／`表现亮眼`／`波动加剧`。
- **不写问句**：问号/悬念 lint 直接 FAIL（`gate.sh 疑问句`：去掉问号后是硬事件就改陈述句，否则撤）。
- **硬定义词**（熔断/创新高/史上首次/N 连涨）必须对源核实定义满足且实际触发 → `gate.sh 数字`（v2.9.30／v2.9.40）。
- **精度**：不许只有形容词没有值（`SOL/HYPE 大跌` ❌ → `SOL/HYPE跌超4%` ✅）。
- **多驱动标的**（黄金/油/大盘/BTC）只写走势、不强行归因；归因查不到就降级为纯行情播报 → `gate.sh 归因`。

**中英混杂**：默认中文。英文只允许专有名词——代币/股票符号（BTC、NVDA）、公司/项目名（Apple、Circle）、政策/法案（CLARITY、FOMC）、机构/交易所（Fed、SEC、Binance）、人名（Trump、Powell）、单位缩写（ETF、IPO、ATH、HBM）。动词/形容词/状态词一律换中文：risk-off→避险、beat→超预期、miss→不及预期、liquidation→爆仓、inflow/outflow→净流入/净流出、bullish/bearish→看多/看空、rally→反弹、halt→停盘。判据：2–4 个中文字能替代且不丢精度就必须换。

**数字与单位**：金额 ≥1 万用 万/亿（`4290万美元`，❌ `$4290W`）｜涨跌幅用 %（❌ `0.82倍`）｜代币符号全大写｜链/平台名首字母大写（Base、Hyperliquid）｜时间窗用 24h/1h（❌ `24小时`）。

**禁用词**：合规雷区（百倍/必涨/翻倍/财富自由/上车/抄底/暴富/稳赚）｜标题党（速来/必看/独家/首发/最强/最全）｜低俗敏感（性暗示/死亡威胁/政治站队）｜空话（值得关注/不容错过/重磅来袭）。

**主轴优先级**（标题要回答「这对持仓/下单意味着什么」）：价格/涨跌幅 ＞ 持仓/资金动作 ＞ 多空/板块分歧 ＞ 能直接传导的政策/事件 ＞ 人物/故事钩子（只作修饰）。

> v2.x 的标题四维自评（总分 ≥32）与加密圈层字典 10-24 用户定废止（字典里的情绪词与 `gate.sh A闸` 情绪虚词判据相反）。

## keywords（`topic.py` 校验：逗号分隔字符串、1–4 个）

- **两档**：① ticker / 代币符号 1–2 个（触发自动打标；美股优先代币化股票 `NVDAX`／`CRCLX`／`AAPLon`）；② 中英文别名或强相关概念 ≤2 个（`NVIDIA`／`英伟达`／`USDC`／`CPI`）。**合计 ≤4**。
- **禁笼统统称**：`山寨币`／`加密`／`加密货币`／`概念`／`板块`／`代币`／`数字资产`——会冲淡主体、误挂实体。
- **例**：NVDA→`NVDAX,NVDA,NVIDIA,英伟达`｜CRCL→`CRCLX,CRCL,Circle,USDC`｜INTC×Apple→`INTC,英特尔,Apple,苹果`｜BTC→`BTC,比特币,Bitcoin`｜黄金→`XAUT,PAXG,黄金,Gold`｜美联储/利率→`BTC,美联储,Fed,利率`。
- **跨市场映射顺序**：① 先试代币化股票（ticker 加 `X`／`on` 后缀探针，看自动打标结果）→ ② 无则用原股票符号 → ③ 与某加密板块强联动用板块代表币 → ④ 纯宏观用 BTC／ETH。港股/中概多数无挂钩代币，用代码或公司名。已知 tag id → `data-quickref.md`。
- **打标核对**：下游错实体由 `downstream.py` 回读（topic.py 建题时自动跑），**改关键词才生效，清 tag 无效**；tradfi 题挂到同名代币化股票/股票永续算等效（`gate.sh 建题核实`）。

## domain / topic_type / desc

- **domain 必传**（topic.py 拒收缺省）：按**标题主语/价格落点**判——加密原生标的为主体，或落点写加密价格 → `crypto`；纯美股/亚股个股与板块、大宗（原油/黄金）、纯宏观（CPI/Fed/美债/非农，落点非加密）→ `tradfi`。灰区：「芯片股崩盘」→ tradfi；「芯片崩拖累 BTC」落点 BTC → crypto。
- **update 不能改域**（domain 只是「在哪张表搜」）→ 建错域只能撤了重建。tradfi 域 tag 照样走代币化 tag，与 crypto 共用。
- **topic_type**（仅 crypto 域生效）：0 主流币（BTC/ETH 及其衍生、宏观风险资产联动）｜1 山寨币（已上主流所的非 BTC/ETH 代币、正式链上项目）｜2 meme（纯社区驱动，无团队/白皮书）。边界：有官网+团队+白皮书 → 山寨。
- **desc 不传**（topic.py 不发此字段；update 改不了 desc）。

## 建后核对清单（topic.py 已做回读，以下是人判部分）

| 数据类型 | 核法 | 不达标 |
|---------|------|-------|
| 涨跌幅窗口 | 标题里的 % 有没有说清是 24h/盘中/收盘/周内 | 模糊 → 改明 |
| 链上持仓/金额 | 是否仍代表当前状态 | 老数据标「截至 X 日」，或按 `gate.sh 时效` 内容时效砍 |
| 第三方机构数据 | ≥2 源交叉或注明来源 | 单源未标 → 加来源 |
| KOL 观点/技术分析 | 标注来源或弱化 | 不作客观事实 |
| 事件被否认/辟谣 | 建后扫最新快讯 | 反转 → update 或撤 |
| 地缘/政策/突发、方向性主张、百亿级资本动作 | 二次核（WebSearch／第二源） | 找不到第二源 → 不建，入 event-watch（`gate.sh 建题核实`） |
| 美股盘中/盘后/盘前价 | 时段口径 | `topic.py` 自动挂收盘复查；口径表 → `gate.sh 时段` |

撤回与修正：内容错（数据硬错/事件被否认/触合规雷区）→ `topic.py cull`，先撤再说；主体成立仅数字偏差 → `topic.py update`（route 档位见 `route.sh`）；过期题数字不改（`gate.sh 过期题`）。
