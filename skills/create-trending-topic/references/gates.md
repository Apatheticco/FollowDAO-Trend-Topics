>   1. **先画实体图，再动任何一条题**：平台／产品／机制 → 派生标的（每个：链＋合约地址＋当下价／市值／成交额）→ 底层资产（正股 ticker）→ 关键事件（时间／数字／当事人）。落台账 `log-action.sh note - 留档 "热点图谱|<名>|…"`。（4Stock 图谱范例 → LESSONS「gates 10-24 沉降」⑧）
>   2. **取价降级梯走到底才许说「核不到」**：followin／`okx.py t` → **`dex.py t <SYM>`（v3.3.6：先查 `contracts.json` 注册表按合约地址取，未钉的列候选并标「未钉死」）** → 社媒实测 → 才落「核不到」。**未钉死的价格不得进标题**——按 symbol 搜「成交额最大」的池也会选到仿盘；核实一次就 `dex.py pin` 钉住，核实过的才是资产；仿盘期（官方未上线）用 `dex.py block` 标住。热点期的「核不到」几乎总是「没走到底」。
>   3. **找一手解释源，二手概括只当线索**：搜索词＝实体图里 ≥2 个名字连用，不是单 ticker；目标是那一篇把机制讲清的。**禁止照抄二手概括的措辞进标题**（反例 09-08 4Stock → LESSONS「11-07 Q16 同步包沉降」）。

>   5. **挂退场与复查**：正股开盘时点 review；次日复查溢价／市值是否回归；消退判据建题时写死（24h 成交额跌破峰值 1/5 或市值腰斩 → 收缩到 1 条）。

## 闸:归因

> - **🔎 归因是查出来的，不是想出来的；查不到就只播报板块行情（v2.9.52 — 08-18 用户点名定则：「下跌或者上涨的归因不要编造，你可以查询看媒体报道；没有合适的归因，你只需要播报板块行情变动即可」）**：
>   - **① 查媒体是前置动作，不是可选步骤**：写任何涨跌诱因前先查该板块/标的当日报道（几个源、degraded／0 条怎么算见闸:建题核实「几个源」表）。**只采信媒体自己做出的因果连接**（"X 板块因 Y 下跌"得是记者写的）；我从"当天还发生了 Z"推导出的诱因一律不算。
>   - **② 查不到板块专属归因 → 降级为纯板块行情播报，这是合法出口不是失败**：标题只写「板块名＋方向＋≤2 个幅度最大的 ticker」（如「存储板块普跌，SNDK跌8%、WDC跌7%」）；宽泛背景（大盘、地缘、风险偏好）写进描述，不进标题。
>   - **③ 降级出口只对板块级开放**（多标的同向、落在窄带，v2.9.48）：单标的纯价格题仍按闸:双要素【缺诱因】不建，出口没有扩大——「存储板块普跌 6%」本身是叙事，「SNDK 跌 5.2%」不是。
>   - **④ 证伪自检**：这个因子昨天在不在、昨天价格什么方向？昨天也在而方向相反 → 删。同一天同板块一条能给因一条不能，差别只在查没查到。
>   - **⑤ 系统给的归因同样待验**，不能拿未验归因去否决另一条题（双重未验）。
>   - **⑥ 判据始终是「这句因果是谁写的」，不是「这个因子今天用过没有」**：有源就能写、没源不能写，删过一次不等于禁用。
>   - **⑦ 查不到诱因、幅度又不过闸:双要素幅度线 → 不建题，也不降级板块题**（双腿全缺维持撤）。
>   - （①–⑦ 判例 2645/2646、CRWV `2651`、RKLB `2648/2649`、08-17/18 收益率正反两日 → LESSONS v2.9.52；压缩前原文 → LESSONS「gates 11-21 沉降」）
>   - **⚡ 归因三问（v2.9.51/52/53 的统一执行入口——建题、改题、复查，落笔任何因果前默念）**：① **这句因果是谁写的？**——记者明写的才算；我从两条事实推的、系统模板生成的，都算没有（51／52①／52⑤）。**①b（v2.9.68 加严）：源里那句因果的两半，和我标题里的两半逐字对得上吗？**对不上＝**借源造因**。**并列即暗示因果：标题里并置的两件事同样过本三问，去掉连接词不豁免**——读者不会把并置当不相关。**压缩/改写标题后必须重念一遍自检句**（v2.9.51），砍字不得砍掉因果链的承重环节。② **这个因子昨天在不在？昨天价格什么方向？**——昨天也在而方向相反，删（52④）。③ **板块断言背后拉了几个标的？**——不足 4 个不落笔；只有 1 个显著异动，是个股题（53）。三问全过再落笔；任一不过走对应出口：删连接只留事实／降级纯行情播报／改写个股题。

>     - **⚠️①c「利好/超预期＋股价下跌」类不走因果闸、走事实闸（v2.9.72 — 08-28 用户点名 2762）**：判据＝标题前半是**当日发生、可证实的公司事件**（财报 beat／获批／中标），后半是同日反向价格——这类是**转折陈述**（利好出尽／杀估值），**不得以「归因反向」撤**。正确动作两步：① **核实前半句真伪**（查财报原文或多源）→ 假＝`事实错误-定义`，撤；② 真则**不撤**；若嫌暗示因果，走 v2.9.36b 先例**改并列陈述**（「X 单日回吐 18%，前一日曾暴涨 178%」式），保留信息、去掉因果暗示。**同一个模板判决可以相反，区别不在句式而在前半句的事实断言真不真**——把事实核查问题当句式问题判，就是 2762 误判的根因。**仍属借源造因、必须撤的三种**：**时间错配**（昨日利好配今日跌）／**真跌因另有其题**（前台已有真诱因题，本题挂了个不相干利好）／**伪诱因**（前半句不是当日可定价事件，「需求增长预期」「机构新进持股」13F 滞后数据）。**⛔ 禁止以「今日第 N 次同模板」单独作为撤因**——模板相同 ≠ 事实相同，每条须独立核实前半句，撤因里必须写出**本条**的证据。（①b/①c 全部判例 11774/2735/2653/2762/2669/2687/2690/2767/2651 → LESSONS「gates 10-24 沉降」⑫）

  - **🟢 判 OK 的题直接上线（v2.9.26 — 08-04 用户授权）**：判定合格的题直接 `topic.py publish`；**「判留」=直接发布，没有第二道关**，故执行默认反转——**先假设该撤，三问全过才上线**：① 说得出**哪个可交易标的**被这条催化定价（闸:A闸）？② 说得出**动作发生在扫描窗内**（闸:时效②）？③ 说得出**与池内已有题锚不重叠**（闸:去重；对照池=B0 **全状态 0/1/2**，v2.9.30）？**任一说不出 → `status=3`，不是"先留着看看"**。
  - **报告 status 以实查为准**：`topic.py` 每次写后已回读；报告前仍 `list` 实查当日题（系统推有数分钟延迟，v2.9.4）。

## 闸:报告格式

- **🖥 第一屏固定三行（v3.4.0 — 09-09 用户定）**：①要你定的 N 项 ②本轮动了什么 ③我自己发现的错；格式与 `ask.py open/post` 发群动作单点见 SKILL §5⑥。判据：用户不往下滚就能回答「我要做什么」。
- **📊 报告表格化优先**（v2.7.9）：报告骨架＝闸:收尾清单六块（＋价格快照），默认表格承载；一句话结论 + 表格，仅纯叙述判断可少量散文。AUTO 尤其严格。（11-07 Q16：原本处重复列的五项骨架改指针，单点在闸:收尾清单）
- **🏦 首扫美股 = 板块聚合展示，不散列个股**（v2.9.22）：首扫报告里美股行情/新闻**按板块归纳成叙事**，每个异动板块一行：`板块名 + 方向幅度 + 代表股`。
  - 板块粒度跟随当天叙事：data-quickref 8 板块矩阵是覆盖基线，可按新闻拆细（如"云服务商"从大科技拆出）。展示口径：≥2 标的同向 >3% 可在报告里并成一行展示——**展示行不算板块断言**；写成板块题或说「板块普涨/普跌」仍须 ≥4 个同板块样本（闸:双要素 v2.9.53）；**留/建板块题须核板块名与成分对得上，`--keep` 理由写「成分:」**（retro1127，4073 软件板块实为 AI 云）；单票独走才单列注明。刷新模式不强制（有板块共振仍归纳）。**聚合是展示方式，不改建题粒度**。
  - **📐 样例模板**（2026-08-04 首跑落定）：一句话基调 + 板块表按幅度强弱排序，表头 `板块｜方向·幅度｜代表股(涨跌%)`，如 `🔦 光通信爆发 ⭐最强｜4股齐涨｜AAOI +16.9%、COHR +9.7%、LITE +9.1%`。**排版铁律**：① 板块内分化用 `｜` 分正负两组标"分化"，别拿领涨掩盖领跌；② 单票独走单列注明；③ 通道缺口行内标 ⚠️ 不静默。**展示≠建题**：展示完必接「先盘存量 → 只补缺口板块」（首跑实测：9 板块异动 8 板块系统已覆盖，只补光通信 1 条）。

## 闸:通道齐备

- **🚦 通道齐备闸 — 报告前强制自查**（v2.9.14＋v2.9.19＋v2.9.69；机械载体＝`checklist.sh start→mark→verify`，清单按 `channels.json` 生成，先列全清单再逐项打勾，verify 不过不得出报告）：
  - **🔢 每个 ✅ 必须附计数证据**：写「调用了什么＋返回几条」，写不出＝虚报视同 ❌。合规：`价格✅(metrics×2批,5+5=10币全到)`、`okx✅(movers 涨12+跌12, OI12)`；违规：`价格✅`、`通道跑齐了`。高频半批陷阱：10 币只拉 5 个当 10 币。每行「✅要数什么」看 `checklist.sh channels` 的 guard 填法；**❌ 项必须写明兜底或标 ⚠️ 半盲**。
  - **🚫 未跑齐禁下的结论**：「池子被盖满/缺口只有 N 条」「今日主线是 X」「干净干轮」「A 是 B 的原因」——全需全景视野，缺项改写「**已跑通道内**未见其他缺口」+ 标 ⚠️ 半盲。**「查不到」只有在通道跑齐后才成立**；大事件日恰恰是最该跑齐通道的日子。
  - **⛔ 模式只有首扫/刷新两种**（v2.8.8）：「2h 轻量轮」「上轮刚扫过」「dump 无未消化线索」都不是模式，刷新的必跑项一个都不能少。
  - **执行位点**：先自查通道、再写三件套，顺序不可倒。

- **报告固定六块**（v2.5.5 + v2.5.9 + v2.9.6）：
